# Farangiz Portfolio

🌐 Premium Dark + Purple & Blue Neon portfolio website

## Tech Stack
- **React** 18
- **Vite** 5
- **Tailwind CSS** 3
- **Vanilla JS animations** (particles, typing effect)

## Features
- 🌍 UZ/EN language toggle
- ✨ Animated particle background
- ⌨️ Typing animation (Hero section)
- 🃏 Glassmorphism project cards
- 📱 Fully responsive (mobile-first)
- 🎨 Purple & Blue neon theme
- 🔭 Scroll-triggered animations

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

```bash
npm install -g vercel
vercel --prod
```

Or connect your GitHub repo to [vercel.com](https://vercel.com)
